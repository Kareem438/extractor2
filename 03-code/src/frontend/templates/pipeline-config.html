What is Pipeline Configuration?

Pipeline configuration allows you to define a series of processing steps that will be applied to your Knowledge Units (KUs). Each step can read data from KU attributes, send it to Claude for processing, and store the results in other attributes.

Template Variables

Use template variables in your prompts to dynamically insert KU data:

  • {{text_content}} - The main text content of the KU
  • {{attr1_value}} through {{attr160_value}} - Custom attribute values
  • Use @ in the prompt textarea to autocomplete cross-book references

Multi-Tag XML Extraction (New!)

Configure tag mappings to extract multiple pieces of information from a single Claude response:

  • Define XML tags that Claude should use in its response (e.g., <summary>, <keywords>)
  • Map each tag to a target attribute where the content will be stored
  • Mark tags as "required" to flag KUs as incomplete if the tag is missing
  • Set a fallback attribute to capture any unmapped tags

Execution Modes

  • Individual: Process each KU separately (default)
  • Grouped: Combine multiple KUs into a single prompt for efficiency
  • Incomplete Only: Retry only KUs marked as incomplete
