What is the Pipeline Dashboard?

The Pipeline Dashboard allows you to monitor and control the processing of Knowledge Units (KUs) through your configured pipeline steps. You can create KUs from extracted data and execute Claude analysis on diagrams and Q&A pairs.

Knowledge Unit Creation

After extracting text and images from pages, you need to create Knowledge Units:

  • Paragraphs: Text content is copied directly to KU
  • Diagrams/Tables/Equations: Skeleton KU created with image reference
  • Q&A Pairs: Question and answer merged into single KU

KU Grouping (New!)

Group multiple KUs into a single Claude prompt for efficiency:

  • Group by L2 Title: KUs under the same L1+L2 title are grouped together
  • Max KUs per Group: Limit how many KUs are combined
  • Token Limit: Alternatively, limit by estimated token count
  • Preview: See grouping breakdown before execution

Execution Modes

  • Individual: Process each KU separately (default, most reliable)
  • Grouped: Combine KUs for faster processing (50-80% cost reduction)
  • Incomplete Only: Retry only KUs marked as incomplete

Dry Run Mode

Enable "Dry Run" to preview what would be sent to Claude without actually making API calls. Results can be saved to a custom attribute for review.
