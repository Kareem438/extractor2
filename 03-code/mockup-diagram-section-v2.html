Verify Pages - Diagram Section V2

Layout: Vertical layout with Knowledge Units preview on the LEFT side under the book page image.

Flow: User selects diagram → Clicks "Add as Diagram" → Expanded section appears on RIGHT with Title, Associated Text, and Claude Analysis

Layout Description

Two-Panel Layout:

LEFT PANEL

  1. Page Image (top) - Shows the full page with diagram selection highlighted in green
  2. Knowledge Units Preview (bottom) - Lists all KUs on this page
    • Each KU shows: number, type, preview text, level, confidence
    • Radio button to select which KU to associate with diagram
    • Selected KU is highlighted
    • Scrollable if many KUs

RIGHT PANEL

  1. Cropped Diagram (top) - Preview of selected diagram area
  2. Section 1: Title - Optional title input with "Select from Page" option
  3. Section 2: Associated Text - Shows selected KU from left panel
  4. Section 3: Claude Analysis - AI analysis with editable result
  5. Action Buttons - Cancel / Save All

User Flow:

  1. User draws selection around diagram on page image (left panel)
  2. Clicks "Add as Diagram" button
  3. Right panel expands with diagram details form
  4. User optionally enters title (or clicks Select to draw title area)
  5. User clicks on a KU in left panel to associate it with the diagram
  6. User clicks "🤖 Analyze" to run Claude Vision
  7. User reviews/edits the analysis
  8. User clicks "💾 Save All"
