Alternative Layout - Compact Version

User Flow Description

Step-by-Step Flow:

  1. User selects diagram area on page image (green selection in OCR mode)
  2. Clicks "Add as Diagram" button
  3. Expanded section appears with three parts:
    • Title: User can type or click "Select Title" to draw a new selection for title text
    • Associated Text: User can select related paragraph or choose from existing knowledge units dropdown
    • Claude Analysis: Click "Run Analysis" to send to Claude Vision API
  4. Claude analyzes the diagram image + title + context
  5. User reviews/edits the analysis result
  6. Clicks "Save All" to store diagram, title, link, and analysis

Data Stored:

  • diagram_images.image_data - The cropped diagram image
  • diagram_images.title - User-provided title (NEW field needed)
  • diagram_images.linked_knowledge_unit_id - Link to associated text
  • diagram_images.description - Claude Vision analysis (editable)
  • diagram_images.diagram_type - Detected type (flowchart, hierarchy, etc.)
  • diagram_images.structured_json - Full AI analysis JSON
