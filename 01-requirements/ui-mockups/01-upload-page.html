Step 3: Define Custom Attribute Names (32 Available)

Define attribute names that will be used for ALL records in this book. You can use these to categorize and tag extracted knowledge units. Attributes 1-8 are system-reserved. Attributes 9-40 are user-defined (32 custom attributes available) - leave blank if not needed.

🔒 System-Reserved Attributes (1-8):
• Attribute 1: related_image (image linking)
• Attribute 2: paddleocr_text (PaddleOCR full result)
• Attribute 3: surya_ocr_text (Surya OCR full result)
• Attribute 4: tesseract_text (Tesseract full result)
• Attribute 5: paddleocr_confidence (0-100)
• Attribute 6: surya_ocr_confidence (0-100)
• Attribute 7: tesseract_confidence (0-100)
• Attribute 8: record_status (enabled/disabled for merge tracking)
These are automatically populated by the system.
💡 How User-Defined Attributes Work:
• Define attribute KEY NAMES here (once per book)
• During verification, you'll only enter VALUES for each record
• Example: If you set Attribute 9 = "Difficulty Level", you'll enter values like "Beginner", "Intermediate", "Advanced" during verification
📌 Important: User-defined attribute names (9-40) will be saved to the database and apply to ALL knowledge units in this book. You can edit these attribute names later via the Book Settings page (accessible from Book Library), and changes will be reflected in the verification interface.

Step 5: Start OCR Processing

📖 How Sequential OCR Works:
• Run one or more OCR engines to extract text from your document
• Images/diagrams are analyzed automatically during the FIRST OCR run
• Click "Evaluate, Split and Mark" when ready to finalize
• System will select the best OCR result based on confidence scores

⚡ OCR Engines (Run independently):

Fast, GPU-accelerated, good for clean text. ~30 mins for 500 pages. Uses 6GB GPU memory.

Slower, higher quality, excellent multilingual support. ~60 mins for 500 pages. Uses 2GB GPU memory.

CPU-based fallback, very reliable. ~45 mins for 500 pages. No GPU required.

After OCR engines complete:

Compares OCR results, selects best text based on confidence, runs splitter and marker agents.

💡 Tip: Run all 3 OCR engines for best quality comparison, then click "Evaluate, Split and Mark" to let the system automatically pick the highest quality result.
