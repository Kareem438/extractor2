Knowledge Extraction System

AI-powered PDF knowledge extraction and processing system for Arabic books. Transforms scanned documents into structured, searchable knowledge units through multi-stage pipelines with human verification.

Version 1.0 Server: localhost:8888 18 Pages 26 API Route Modules Updated: 2026-02-14

System Overview

A web-based system running as a FastAPI server with PostgreSQL + ChromaDB backends. Users upload Arabic PDF books, run AI-powered layout detection and OCR (local or cloud), verify results through canvas-based review interfaces, configure Claude AI enrichment pipelines, and export structured knowledge units. All pages are vanilla HTML/CSS/JS with Canvas API for image annotation.

1. Book Library

/library
Central hub for managing all uploaded books

Layout

  • Header with gradient background, total book count and statistics
  • Action bar with search input and "Upload New Book" button
  • Book cards grid: name, page count, status badge, progress bar, action buttons
  • OCR model status indicators (Surya, EasyOCR, YOLO)

User Experience

User sees all books at a glance with processing status. Search/filter to find books. Click a card to navigate to settings or processing. Quick actions: Verify, View, Pause, Monitor, Delete.

2. Upload

/upload
Upload PDF documents and configure initial processing settings

Layout

  • Top navigation bar with links to all major pages
  • Drag-and-drop upload zone with file browser fallback
  • Processing preset selector (Quick / Balanced / Deep)
  • Language configuration (Arabic, English, mixed)
  • Custom attribute configuration panel (up to 72 user-defined fields)
  • Multi-PDF upload modal for batch processing

User Experience

Drag a PDF onto the upload zone, select processing preset and language, configure custom attributes, click Upload. File is stored and pages scanned at 600 DPI. Warning banner if scanning hasn't run. Redirects to Book Settings or Auto-Slicer after upload.

4. Auto-Slicer

/auto-slicer?book_id=X
Bulk page processing with YOLO layout detection, title hierarchy, and cloud extraction

Layout

  • Recommended Workflow guide
  • Page Viewer with zoom controls and page navigation
  • Title Configuration (L1 Chapter / L2 Topic / L3 Sub-topic hierarchy)
  • Page Range selector and YOLO Detection Classes toggles
  • Action buttons: Run Detection, Run OCR, Auto-Boundaries
  • Cloud Extraction section: model dropdown (qwen-vl-max, qwen3-vl-plus, qwen3-vl-flash), Start/Pause/Cancel, progress bar, review link

User Experience

Select a book, configure title hierarchy and detection classes, run YOLO detection on page ranges. For cloud path: select Qwen model, start extraction, monitor progress with real-time polling. After completion, link appears to Knowledge Page Review.

5. Layout Review

/layout-review?book_id=X
Canvas-based review and editing of YOLO-detected regions

Layout

  • Three-panel layout: region list (left), canvas (center), editor (right)
  • Canvas shows page image with colored bounding box overlays per detection class
  • Region list with class labels, selection tools, link mode toggle
  • Editor panel: region details, context menu, advanced tools
  • Toolbar: zoom, Arabic mode, keyboard shortcuts, "Ready for Extraction" toggle

User Experience

Navigate page by page. Click regions to select, drag to resize/move, right-click for context menu. Merge/split regions, change class types, link diagrams to paragraphs, link paragraphs to L3 titles. Mark pages "Ready for Extraction" as few-shot examples for cloud OCR. Skip pages to exclude from processing.

6. Knowledge Page Review NEW

/knowledge-page-review?book_id=X
Review cloud OCR results grouped by L3 title before converting to KU records

Layout

  • Top nav: book name, KP count, overall status, "Convert All Ready → KU" button
  • Left sidebar: KP navigator (prev/next), status filter, element cards list, "Add Element" button
  • Center: Canvas with page image + color-coded bbox overlays, page selector, zoom, show/hide toggles
  • Right panel: Element editor — type dropdown, Arabic text (RTL), page number, order, confidence, bbox, move/delete
  • Bottom bar: Save, Ready toggle, Convert button

User Experience

Navigate between knowledge pages (grouped by L3 title). Each shows title, page range, element count, status (extracted → reviewed → ready_to_convert → converted). Click elements to edit text, type, order, bbox. Add/remove elements. Save persists changes. "Ready" toggle marks for conversion. "Convert All Ready" batch-creates KU + paragraph records. Filter by status. Color-coded bbox overlays by element type (paragraph=green, heading=orange, footnote=purple, etc.).
